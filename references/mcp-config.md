# MCP server configuration (game engines)

Use when the user asks how to hook Claude Code, Cursor, Copilot, or Desktop to Unity / Godot / Unreal. Emit copy-paste JSON for their OS and client. Do not invent ports.

## Client config files

| Client | File |
|---|---|
| Claude Code | project `.mcp.json` (or user `~/.claude.json`) |
| Claude Desktop | macOS `~/Library/Application Support/Claude/claude_desktop_config.json` · Windows `%APPDATA%\Claude\claude_desktop_config.json` |
| Cursor | project `.cursor/mcp.json` |
| VS Code Copilot | project `.vscode/mcp.json` |
| Windsurf | `~/.windsurf/mcp.json` or `%APPDATA%\Windsurf\mcp.json` |
| Codex | `~/.codex/config.toml` or project `.codex/config.toml` |
| Gemini CLI | project `.gemini/settings.json` |

Rules that bite
- Absolute paths. Many clients do not expand `~`.
- Claude Desktop is stdio-first. Remote HTTP often needs `npx mcp-remote` as a stdio shim.
- Restart the client after editing. Closing a window is not a restart on Windows Desktop.
- Editor must be open and Ready before the client lists tools.
- One engine instance per server entry. Use project-path / port when several editors are open.

Generic stdio shape

```json
{
  "mcpServers": {
    "NAME": {
      "command": "ABSOLUTE_COMMAND",
      "args": ["..."],
      "env": {}
    }
  }
}
```

Generic HTTP shape (Claude Code, Cursor, VS Code)

```json
{
  "mcpServers": {
    "NAME": {
      "type": "http",
      "url": "http://127.0.0.1:PORT/mcp"
    }
  }
}
```

## Official Unity MCP (com.unity.ai.assistant, Unity 6+)

Topology — client → Unity relay (`--mcp`) → Editor bridge.

1. Edit > Project Settings > AI > Unity MCP. Bridge must be **Running**.
2. Integrations → client → Configure (preferred).
3. First connect is **Pending**. Accept in that same settings page. Assistant-via-gateway is auto-approved.
4. Confirm the client under Connected Clients. Smoke test — read console.

Relay binary (created under `~/.unity/relay/` when the Editor starts)

| OS | Path |
|---|---|
| macOS Apple Silicon | `/Users/YOU/.unity/relay/relay_mac_arm64.app/Contents/MacOS/relay_mac_arm64` |
| macOS Intel | `/Users/YOU/.unity/relay/relay_mac_x64.app/Contents/MacOS/relay_mac_x64` |
| Windows | `C:/Users/YOU/.unity/relay/relay_win.exe` |
| Linux | `/home/YOU/.unity/relay/relay_linux` |

```json
{
  "mcpServers": {
    "unity-mcp": {
      "command": "C:/Users/YOU/.unity/relay/relay_win.exe",
      "args": ["--mcp"]
    }
  }
}
```

Several Editors open — add `"--project-path", "D:/MyUnityProject"` to args.

Claude Code plugin path (separate from raw MCP) — official Unity plugin for Claude Code installs skills + CLI + MCP with less JSON. Prefer that when the user is on Claude Code.

## Community Unity-MCP / AI Game Developer (IvanMurzak)

Topology — client ⇄ gamedev-mcp-server ⇄ plugin (SignalR).

- Server binary auto-downloaded to `Library/mcp-server/{platform}/`.
- Port is **SHA256(lowercase project dir) mapped to 20000–29999**. Same path → same port. Override in Window > AI Game Developer if needed.
- Config file `UserSettings/AI-Game-Developer-Config.json` — host, transportMethod (`streamableHttp` / `stdio`), authOption (`none` / `required`), token, timeoutMs (10000), keepConnected, tools/prompts/resources toggles.

HTTP client

```json
{
  "mcpServers": {
    "ai-game-developer": {
      "type": "http",
      "url": "http://localhost:PORT"
    }
  }
}
```

stdio client

```json
{
  "mcpServers": {
    "ai-game-developer": {
      "command": "<project>/Library/mcp-server/<platform>/unity-mcp-server",
      "args": ["port=PORT", "plugin-timeout=10000", "client-transport=stdio"]
    }
  }
}
```

CLI extras — `unity-mcp-cli status|open|wait-for-ready|run-tool`. Auth token required when `authOption=required`.

## Godot AI (hi-godot / dlight family)

Topology

```
MCP client → godot-ai attach (stdio) → Python HTTP :8000 → editor plugin WebSocket :9500
```

Do **not** point the client at bare `http://127.0.0.1:8000/mcp`. V4 attach is authenticated and rotates capabilities. Use the dock **Configure** button.

1. Addon at `addons/godot_ai/plugin.cfg` (not `addons/plugin.cfg`).
2. Project Settings > Plugins > enable Godot AI.
3. Dock → Configure next to the client (or Configure all).
4. Scope — Editor Settings > Plugins > godot_ai/mcp_client_scope = `user` (default) or `project`.

Manual Desktop fallback often looks like `uvx` / `godot-ai attach` generated by the dock. Copy that command; do not invent flags.

Other Godot stacks
- GDAI MCP — `gdai_mcp_project_config.json`; default ports **3571** (MCP) and **3572** (runtime / simulate_input). Mirror those values in the client `env` block.
- Older node Godot-MCP — editor tools on **9500**; client stdio to a local `server/dist/index.js`.
- Port 8000 busy — dock “Free Port & Replace Server” only for a server you own.

## Official Unreal MCP (UE 5.8 Experimental)

Topology — in-editor HTTP server, loopback only.

Editor Preferences > General > Model Context Protocol

| Pref | Default |
|---|---|
| Auto Start Server | false |
| Server Port Number | 8000 |
| Server URL Path | /mcp |
| Enable Tool Search | true (list returns meta-tools, not every schema) |

URL — `http://127.0.0.1:8000/mcp`. Advertised name `unreal-mcp`.
Start — `ModelContextProtocol.StartServer [port]` or `-ModelContextProtocolStartServer`.
Client files — `ModelContextProtocol.GenerateClientConfig ClaudeCode|Cursor|VSCode|Gemini|Codex|All`

```json
{
  "mcpServers": {
    "unreal-mcp": {
      "type": "http",
      "url": "http://127.0.0.1:8000/mcp"
    }
  }
}
```

Security — **no auth**. Loopback + Origin check only. Do not expose past this machine.

Also enable whatever Toolsets the project needs; missing families usually mean a plugin is off.

## Community ue-mcp (npx)

Topology — TypeScript MCP server → WebSocket `ws://localhost:9877` → `Plugins/UE_MCP_Bridge`.

```bash
npx ue-mcp init
```

Writes bridge plugin, enables PythonScriptPlugin + category plugins, scaffolds `ue-mcp.yml`, can write client configs. Per-machine state in `~/.ue-mcp/`.

```json
{
  "mcpServers": {
    "ue-mcp": {
      "command": "npx",
      "args": ["ue-mcp", "C:/path/to/MyGame.uproject"]
    }
  }
}
```

Windows paths in JSON — forward slashes. `npx ue-mcp doctor` after updates. Switch project with `project(action="set_project")`. Filesystem tools work with the editor closed; bridge actions do not.

Other Unreal community ports you may see (do not mix stacks)
- Remote Control API **30010**
- Python Remote Execution multicast **6766** / inverted TCP ~**6776**
- Some C++ bridges **55557** or **3000**
- ChiR24-style automation **8091**

UE 5.3+ Python Remote Execution — multicast bind often must be `0.0.0.0` not `127.0.0.1`.

## Shared GameDev-MCP-Server

One binary for Unity + Godot + Unreal plugins.

```
./gamedev-mcp-server --port 8080 --client-transport stdio
```

| Flag / env | Default | Meaning |
|---|---|---|
| `--port` / MCP_PLUGIN_PORT | 8080 | HTTP client + SignalR plugin |
| `--client-transport` | streamableHttp | or stdio |
| `--authorization` | none | or required |
| `--token` | — | bearer when required |
| `--plugin-timeout` | 10000 | ms |

`gamedev-mcp-server configure --agent claude-code` writes the client file.

## What to emit from the skill

When the user wants MCP wired
1. Name the engine stack (official vs community). Do not mix ports across stacks.
2. Give the exact client file path for their OS.
3. Paste one JSON block with absolute-path placeholders.
4. List the 4 live checks — editor open, plugin enabled, client restarted, tools visible.
5. First agent prompt after connect — ping / list tools / screenshot. Not “build the game”.

If they only want prompts for gameplay, do not dump this file. Point at one JSON block and stop.
