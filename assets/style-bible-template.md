# Style Bible template

Copy this block to the top of every image or video prompt. Fill brackets. Delete unused lines. Keep it under 8 lines.

```
STYLE LOCK — [PROJECT NAME]
Camera — [side-view orthographic / 2:1 iso 30° / top-down / 3/4 painterly / first-person viewmodel]
Render — [32px pixel, hard edges / hand-painted, visible strokes / low-poly flat / inked comic / PBR realistic]
Line — [none / 1px dark wrap / painted edge only]
Palette — [6–12 named or hex colors]. Forbidden — [neon / pure black / skin-pore detail / etc.]
Light — [soft north-west / warm key left, cool fill / overcast]
Silhouette — [read weapon and hat at 32px / chunky shapes / no skinny props]
Banned — text, watermark, logo, real-person likeness, franchise marks, extra limbs, [style-specific bans]
```

Character lock (paste under the Bible when the subject is a person or creature)

```
CHAR LOCK — [NAME]
[species], [body shape], [hair], [face mark], [outfit], [signature prop], [2 material notes]
Always use these words. Do not synonymize.
```

Tile / prop lock

```
SET LOCK
Angle frozen. Light frozen. Outline weight frozen.
Only the object noun changes.
Tile size [N]x[N]. Transparent background.
```
