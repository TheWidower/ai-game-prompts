# AI Game Prompts

Grok skill for production-ready game-development prompts and engine integration.

Covers image and video asset prompts, style bibles, GDD / vibe-coding text, Unity / Godot / Unreal import, and MCP client config.

## Install

Copy this folder into your Grok skills directory as `ai-game-prompts/`.

## Layout

- `SKILL.md` — router, intake, output shapes
- `references/` — image, video, text, engine, MCP, playbook
- `assets/` — style bible, import cheatsheet, MCP templates
- `scripts/emit-mcp-config.py` — emit client config for a named stack
